# NAATI CCL English–Cantonese: 100-Dialogue Practice Pack

This independent pack contains **100 original practice dialogues**, arranged as **50 cross-topic two-dialogue mock tests**, covering all 12 broad CCL topic areas. The web app uses the same final dataset as the scripts and model answer key.

## Current structure

- 100 dialogues / 1394 source segments
- 12–16 segments per dialogue
- 267–327 English-equivalent words per dialogue
- maximum segment length 35 English-equivalent words
- 50 mock tests, always with two different topic areas
- calibrated synthetic MP3 source audio with browser-speech fallback

## How to use it

Use the website for the cleanest blind-practice flow. For offline review, keep `SOURCE_SCRIPTS.md` and `MODEL_ANSWERS.md` closed until you finish a dialogue or mock. Record yourself, preserve names/numbers/conditions, interpret in first person, and use `SELF_REVIEW_SHEET.md` to tag recurring errors.

## Audio

The generated MP3s are **independent synthetic practice audio**, not NAATI recordings. Default 1.0× pace is calibrated to the average pace measured from NAATI's downloadable Cantonese practice recordings. See `AUDIO_CALIBRATION.md`.
