# Cantonese script generation specification — CCL native-source edition

This is the operational writing specification for the English ⇄ Cantonese CCL practice bank.

It has two simultaneous targets:

1. **native, human-like spoken Hong Kong Cantonese**; and
2. **exam-useful lexical transfer** — the Cantonese source must actually require the candidate to interpret Cantonese into English rather than handing them English terminology inside the Cantonese utterance.

The second requirement is intentionally stricter than ordinary Hong Kong sociolinguistic practice. Real Cantonese-English code-switching exists, but this is an interpreting-practice corpus, not a naturalistic code-switching corpus.

## 1. Speaker and language contract

- Professional / officer (`P`) speaks English.
- Immigrant / community client (`C`) speaks Cantonese.
- Cantonese target is **natural spoken Hong Kong Cantonese**, not Standard Written Chinese read aloud.
- The client is a competent adult, not a learner caricature.
- **Cantonese source turns should not contain English lexical terms.**
- A concept that can be said in Cantonese must be realised in Cantonese, even if Hong Kong speakers sometimes code-switch in ordinary life.
- Proper names and labels should normally be translated, conventionalised, or phonetically rendered into Chinese for the Cantonese source when doing so keeps the item interpretable.
- Avoid designing Cantonese-source segments around opaque alphabetic codes. Prefer scoreable content that can be naturally spoken in Cantonese.

Examples of the target principle:

| English concept | Cantonese-source preference |
|---|---|
| Facebook | 臉書 |
| Australian Business Number / ABN | 澳洲商業號碼 |
| payroll | 出糧系統 / 糧務（按情境） |
| pending transaction | 待處理交易 / 仲未正式過數嘅交易 |
| real-estate agent | 地產代理 |
| upload | 上載 |
| email | 電郵 |
| reference number | 參考編號 |
| direct debit | 自動扣帳 |
| insurance claim | 保險索償 |
| policy excess | 自付額 |

Do not keep an English item merely because it is common in bilingual Hong Kong speech. The candidate should have to produce the English term.

## 2. Generate Cantonese from the situation, never from an English sentence

For every Cantonese turn, generate in this order:

1. **Situation:** what has just happened in the conversation?
2. **Knowledge state:** what does the client know, assume, misunderstand, remember or need confirmed?
3. **Social action:** are they requesting, correcting, checking, challenging, accepting, refusing, worrying, deciding, thanking, repairing or clarifying?
4. **Persona/register:** age, length of time in Australia, system familiarity, urgency, emotional state and relationship to the officer.
5. **Information payload:** dates, money, names, conditions, documents, consequences.
6. **Cantonese information structure:** what is topical/old information, what is new, what can be omitted, what needs contrastive focus?
7. **Turn shape:** acknowledgement, fragment, repair, short question, explanation, consequence check, etc.
8. **Discourse marker / particle:** only if the action calls for it.
9. **English model interpretation:** write this *after* the Cantonese, preserving factual and pragmatic meaning.

Never perform this process:

> English source → word/phrase substitution → add Cantonese particles.

That produces translationese even when every character is technically Cantonese.

## 3. Spoken-Cantonese lexical and grammatical defaults

Prefer ordinary spoken Hong Kong forms where the register permits:

| Avoid as routine speech | Prefer in ordinary speech |
|---|---|
| 現在 | 而家 |
| 沒有 | 冇 |
| 這個 / 那個 | 呢個 / 嗰個 |
| 這些 / 那些 | 呢啲 / 嗰啲 |
| 他 / 她 / 他們 | 佢 / 佢哋 |
| 什麼 | 乜嘢 |
| 哪裡 | 邊度 |
| 是不是 | 係咪 |
| 怎麼 / 如何 | 點 / 點樣 |
| 但是 | 但係 |
| 此外 | 同埋 / 仲有 |
| 給 | 畀 |
| 在 | 喺 |
| 來 | 嚟 |

Formal wording can occur when a client quotes or reads a letter, form, law or notice. The surrounding utterance must still sound spoken.

## 4. Native information structure

Cantonese dialogue is context-dependent. Do not repeat full noun phrases just because the English translation would.

First mention:

`房東上星期寄嗰封加租通知`

Later:

`嗰封信`

Later still, when obvious:

`我真係冇收到呀。`

Use zero subjects/objects where the referent is recoverable. Repetition should serve contrast, correction or disambiguation rather than mirror English syntax.

Topic-comment packaging should be natural:

- `嗰筆錢，我到而家都唔知點解會扣咗。`
- `星期五個限期，我最驚就係趕唔切。`
- `份證明我有，不過原本嗰份留咗喺屋企。`

## 5. Turn rhythm: conversations are not mini-essays

A 12–16 segment dialogue should mix:

- very short acknowledgements or change-of-state responses;
- short clarification/repair questions;
- medium explanatory turns;
- a few dense turns with dates, money, conditions or consequences.

Useful short turns include:

- `哦，原來係咁。`
- `係呀。`
- `唔係，係星期四。`
- `咁就好喇。`
- `等陣，係四百八十蚊？`

Do not make every client turn the same length or clause count.

## 6. Interactional diversity

Each dialogue needs a real conversational trajectory rather than a checklist.

Possible events include:

- hearing repair;
- self-repair;
- wrong-referent correction;
- number/date confirmation;
- clarification of a condition;
- consequence check;
- polite request;
- low-level worry or frustration;
- challenge/objection;
- acceptance/relief;
- decision based on new information.

Use only what the scenario motivates. Do not force the same repair or review question into every dialogue.

Examples:

### Hearing / number repair

`唔好意思，你頭先話係四百八十，定四百八呀？`

### Self-repair

`我係上星期五交嘅——唔係，應該係星期四晚先啱。`

### Referential correction

`唔係嗰份，我講緊係續租嗰張表呀。`

### Consequence check

`咁如果我今日補唔到，係咪就當我過咗期？`

## 7. Sentence-final particles and stance

Particles are interactional grammar, not decoration.

Common written forms include:

`呀`, `啊`, `啦`, `喇`, `喎`, `啫`, `㗎`, `嘛`, `咩`, `囉`, `呢`, `嘅`, `啩`.

Rules:

- choose a particle because of stance/action, not because the sentence “needs Cantonese flavour”;
- not every turn needs one;
- do not rotate particles mechanically to satisfy a variety metric;
- do not end most questions with the same `呀`;
- do not attach a random particle after translating an English sentence;
- particle clusters should be uncommon and motivated;
- English model answers preserve challenge, doubt, insistence, relief or politeness rather than translating particles literally.

Example:

`你頭先唔係話今日會搞掂嘅咩？`

A useful English model is:

`But didn’t you say earlier that this would be sorted out today?`

The model carries the corrective stance without inventing a one-word translation for `咩`.

## 8. Discourse markers

Useful resources include:

`其實`, `咁`, `即係`, `但係`, `不過`, `同埋`, `仲有`, `所以`, `跟住`, `原來`, `咁樣`.

Use them to perform discourse work. Do not put the same marker at the start of several consecutive client turns.

Particular risks:

- `咁` is common but very easy for generators to overuse;
- `其實` should reframe or contrast, not mechanically translate “actually”;
- `即係` is especially useful for inference/confirmation, but should not appear in every dialogue at the same position.

## 9. Politeness and directness

Do not convert every English request into `請問`.

Natural resources include:

- `想問下…`
- `我想確認下…`
- `唔好意思，我想問…`
- `可唔可以麻煩你…`
- `你可唔可以幫我睇下…`
- `麻煩你幫我改返個地址。`

A client can be polite and direct:

`呢筆錢我真係唔明點解會扣咗，你可唔可以幫我查返？`

### 唔該 vs 多謝

Choose based on the social event, not an English “thank you” dictionary substitution.

- routine request/service assistance often favours `唔該`;
- stronger gratitude for a benefit/commitment can favour `多謝` / `多謝晒`;
- sometimes no explicit thanks is the natural next turn.

## 10. Negative directives

Use `唔好` and `咪` according to context and interpersonal force rather than as interchangeable variants.

Examples:

`咁我住先唔再交第二份申請。`

`即係而家唔好再交多一份，係咪？`

Client-to-authority speech should not become casually brusque simply to increase variety.

## 11. Exam-specific no-English-source rule

This section overrides ordinary Hong Kong code-switching norms for this corpus.

### Hard principle

**If an English lexical item has a reasonable Cantonese expression, the Cantonese source must use the Cantonese expression.**

Bad for this practice bank:

`我喺 myGov 見到個 claim 係 rejected。`

Better exam source:

`我喺政府個網上帳戶見到宗索償畀人拒絕咗，但係佢冇寫清楚欠咩文件。`

Bad:

`個 transaction 仲係 pending。`

Better:

`嗰筆交易仲顯示待處理，未正式過數。`

Bad:

`我想 upload 份 document。`

Better:

`我想上載份文件。`

Bad:

`我喺 Facebook 見到個通知。`

Target style following the supplied sample convention:

`我喺臉書見到個通知。`

### Proper nouns / institutions

Prefer a meaningful Cantonese name or established Chinese rendering when possible. If no established form exists, use a natural Chinese phonetic rendering or redesign the scenario so the term is not required in a Cantonese-source segment.

The goal is not to create bizarre long translations. The goal is to preserve a **markable Cantonese → English transfer task**.

### Acronyms

Do not fill Cantonese-source turns with `ABN`, `TFN`, `ATO`, `AFCA`, `NCAT`, `USI`, etc. Use the Cantonese concept and let the English model supply the standard English name/acronym when appropriate.

If an opaque alphanumeric reference code itself is genuinely scoreable, prefer numeric-only codes or redesign the detail. Alphabetic code reading is a special case, not permission for lexical code-switching.

## 12. Persona variation

Choose a lightweight client persona before writing, but do not state it in the script.

### Newly arrived parent

- less system knowledge;
- practical clarification and consequence questions;
- respectful but competent;
- no artificially broken Cantonese.

### Older long-term migrant

- confident everyday Cantonese;
- may be less comfortable with digital procedures;
- direct practical questions are natural.

### Young worker/student

- faster/shorter turns and casual discourse possible;
- still use Cantonese lexical terms in source because of the exam rule.

### Small-business owner / professional immigrant

- precise financial/process questions;
- may challenge inconsistencies directly;
- terminology should be Cantonese-realised in source, then mapped to official English in the model.

### Vulnerable/urgent client

- emotional pressure may shorten or fragment turns;
- retain competent adult language;
- focus on consequences and immediate action.

Variation must come from **different knowledge, actions and discourse habits**, not random synonym/particle substitution.

## 13. Avoid sentence-pattern reuse

Exact duplicate sentences across unrelated dialogues are blocking defects.

Near-duplicate skeletons are also defects even when nouns differ.

Reject families such as:

- `我今日收到 X，我唔肯定 X 對我嘅情況有咩意思。`
- `我最擔心係 X，我想喺 Y 之前處理好。`
- `你可唔可以講下 X 對我個案有咩影響，同埋我下一步要做咩？`
- `呢啲夠唔夠開始處理，定係要等齊所有證明先交？`
- `下一步係 X，並保留確認紀錄。`

These may each be plausible once. Reusing the architecture throughout a 100-dialogue bank is synthetic.

Before approving a dialogue, ask what makes *this specific person* choose *this specific next turn* based on what the officer just said.

## 14. English model-answer rules

Write the English model after the Cantonese source.

Preserve:

- first person;
- propositional details;
- certainty/doubt;
- politeness/directness;
- correction/challenge;
- emotional stance where material;
- referential continuity;
- dates, amounts and conditions.

Do not preserve Cantonese word order mechanically.

Do not add English filler for every particle.

For Cantonese lexical terms, use natural target-English institutional terminology in the model where appropriate. This is exactly the vocabulary transfer the exercise is supposed to train.

## 15. Bank-level diversity gates

Treat these as corpus-level quality requirements:

- no exact cross-dialogue Cantonese sentence reuse;
- very low near-duplicate structural reuse;
- no five/four-template rotation masquerading as diversity;
- client openings and closings vary by scenario;
- some client turns are short;
- repairs/confirmations occur where naturally motivated;
- no single particle dominates because of a generator tic;
- Standard Written Chinese markers stay exceptional outside quoted written material;
- **Latin/English lexical tokens in Cantonese source should be zero by default**;
- numbers, dates and consequences remain scoreable;
- every dialogue has its own conversational trajectory rather than a topic-template trajectory.

## 16. Final read-aloud gate

Read every Cantonese source turn aloud at normal Hong Kong conversational pace.

Approve only if:

- it can be said naturally in one or two breath groups;
- clause order feels Cantonese rather than translated English;
- recoverable subjects/objects are not needlessly repeated;
- the particle ending feels motivated;
- the client sounds like a real person reacting to the previous turn;
- no English term has leaked into the Cantonese source simply for convenience;
- the turn is materially distinct from other dialogues in the bank.

If the line is grammatically correct but sounds like something written by a translation engine, rewrite it.
